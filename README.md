# Генератор Судоку на базі алгоритмів ШІ

**Дисципліна:** Основи штучного інтелекту  
**Виконала:** Захарук Софія, КН-3

## Загальний опис проєкту
Цей проєкт повноцінна гра Судоку з банальним графічним інтерфейсом, де всі ігрові поля створюються динамічно за допомогою алгоритмів штучного інтелекту. Замість використання наперед заготовлених шаблонів, програма щоразу самостійно генерує унікальну головоломку обраного розміру (6x6, 9x9 або 16x16) та складності.

## Алгоритмічна складова (ШІ)
Генерація ігрового поля реалізована через підхід **задачі задоволення обмежень (Constraint Satisfaction Problem - CSP)**. Основний алгоритмічний рушій — **пошук з поверненням (Backtracking)**.

Процес створення нової гри відбувається у два етапи:

1. **Генерація ідеального поля (Backtracking + Randomization)**
   Алгоритм рекурсивно проходить по порожній сітці і намагається підставити значення у кожну клітинку, жорстко перевіряючи правила гри (унікальність у рядку, стовпці та внутрішньому блоці). Якщо на певному кроці жодне число не підходить, алгоритм робить "крок назад" і змінює попереднє рішення. 
   Щоб кожна нова гра була унікальною, масив дозволених символів перемішується генератором псевдовипадкових чисел перед кожною спробою підстановки.

2. **Створення головоломки (Деградація поля)**
   Після створення повністю правильного поля, ШІ зберігає його в пам'яті як прихований розв'язок. Далі, залежно від обраної складності, алгоритм вираховує необхідний відсоток клітинок:
   - Легка: видаляється ~35%
   - Середня: видаляється ~48%
   - Складна: видаляється ~60%
   Обрані клітинки випадковим чином очищаються, формуючи завдання для гравця.

## Архітектура інтерфейсу та цікаві рішення
Проєкт написаний на Python з використанням вбудованої бібліотеки `tkinter`. Під час розробки я реалізувала кілька нестандартних підходів для покращення UX:

- **Реактивна перевірка вводу (Observer Pattern):** У грі навмисно немає кнопки "Перевірити". До кожної порожньої клітинки прив'язаний слухач подій (`trace_add`). Щойно гравець вводить символ, програма миттєво перехоплює його, порівнює з прихованим розв'язком і одразу реагує: блокує клітинку зеленим кольором (якщо хід правильний) або зараховує помилку і підсвічує червоним.
- **Масштабованість та Hexadoku:** ШІ вміє автоматично перераховувати обмеження для різних внутрішніх блоків (2x3, 3x3, 4x4). Для найбільшого формату (16x16) я адаптувала гру під класичний стандарт Hexadoku: замість двозначних чисел використовуються символи `1-9` та літери `A-G`. Це дозволило зберегти миттєву перевірку при натисканні однієї клавіші.
- **Гейміфікація:** Додано ліміт на помилки (гравець програє після 3 хибних ходів) та систему з 3 підказок, яка програмно симулює правильний ввід користувача у випадкову порожню клітинку. Вікно гри також динамічно підлаштовує свій розмір під обраний масштаб поля.
